# FabricAI

Initial project structure for a fabric image classification project.

## Project folders

- `training/`: ML training notebooks and scripts will go here later. Training is planned for Google Colab.
- `model/`: The trained fabric classification model and related model files will go here later.
- `backend/`: Server-side code for using the model will go here later.
- `frontend/`: User interface code for interacting with the application will go here later.
